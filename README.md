# Jerry SDLC

Jerry SDLC is a zero-init Codex plugin for risk-aware multi-agent planning, QA, review, and release-readiness workflows.

The project is under phased development and must not yet be treated as a production release control. Its live team persists candidate-bound local evidence and deterministically re-aggregates verdicts, but check execution is unattested and fully privileged; independent assurance, adjudication, portability, and evaluation gates remain open. See `PLAN.md`, `PHASE-STATUS.md`, and `PHASE-1-EVIDENCE.md`.
